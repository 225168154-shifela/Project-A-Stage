# PAP521S - Programming in Practice  
## Project A: Municipal Financial Management System (MFMS)

### 1. Introduction
The Municipal Financial Management System (MFMS) was developed as part of the PAP521S course. It is a foundation system built in ANSI C (C99) to demonstrate programming concepts such as arrays, strings, loops, and functions. The system manages employees, budgets, suppliers, and assets for a municipality.

### 2. Problem Description
Municipalities face challenges in managing financial and administrative data. Tasks like tracking employee salaries, monitoring departmental budgets, maintaining supplier records, and registering assets are essential but time‑consuming. The MFMS addresses these issues by providing a structured, menu‑driven application.

### 3. Objectives
- Design a modular, menu‑driven C application.  
- Apply programming concepts (variables, arrays, strings, loops, functions).  
- Validate user input to prevent invalid data entry.  
- Implement modules for employee, budget, supplier, and asset management.  
- Generate basic reports summarizing system data.  
- Collaborate effectively using GitHub for version control.  

### 4. System Features
- **Employee Management**: Add, search, calculate salaries, display employees.  
- **Budget Management**: Enter budgets, record expenditure, calculate remaining funds, check status.  
- **Supplier Management**: Store supplier details, search suppliers, display supplier list.  
- **Asset Management**: Register assets with ID, type, value, condition.  
- **Reports**: Summaries of employees, budgets, suppliers, and assets.  

### 5. Program Design
The program is modular, with separate `.c` and `.h` files for each component. Functions such as `addEmployee()`, `calculateBudget()`, and `displayReports()` ensure clear organization. Arrays and strings are used for data storage, with string functions (`strcmp`, `strlen`, `strcpy`) applied for searching and validation. Input validation prevents negative salaries, invalid budgets, and empty names.

### 6. Challenges
- Designing modular functions without a large `main()`.  
- Handling invalid input and ensuring proper validation.  
- Managing arrays and string operations effectively.  
- Coordinating group contributions and GitHub commits.  

### 7. Solutions
- Divided responsibilities among group members for modular development.  
- Applied input validation checks to prevent invalid data entry.  
- Used GitHub for version control to track contributions.  
- Conducted group testing sessions to identify and fix errors.  

### 8. Conclusion
The MFMS demonstrates the application of fundamental C programming concepts to solve a realistic problem. The project provided valuable experience in modular design, teamwork, and version control. Project A serves as the foundation for Project B, where the system will be extended and improved.
